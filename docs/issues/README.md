# 问题登记

本目录登记跨主题、需要先行处理的缺陷与缺口，供修复会话按序处理。

约定：

- 本目录**不是权威规格**，不替代各主题文档的"执行与验收"。每条只记录缺陷/缺口、证据与建议修复；方案本身写回对应主题文档。
- 每条有稳定编号与状态：`待处理` / `进行中` / `已修复`（修复后在条目内注明落点，或删除条目）。编号不复用。
- 与 [01 的真机可移植性约束](../design/01-hardware.md#真机可移植性约束2026-11-18) 十条对应，条款不在此重复。
