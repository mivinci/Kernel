# 008 启动包四项待用户确认（阻塞 T1）

状态：阻塞（需用户拍板）　优先级：P0

`docs/design/07-boot.md` 篇末已列，实现前必须定：

1. **定位与传递**：DTB `/chosen` 的 initrd 起止 / 固定物理地址 / 内核内嵌；两架构与真实 U-Boot 必须一致。
2. **校验与信任**：FNV-1a64 覆盖范围是否含头自身 checksum 字段；校验失败是拒启还是仅报告；明确它不是签名。
3. **对齐规则**：段与 ELF 是否要求 4 KiB 对齐（现装载器逐页复制，任意偏移可行）。
4. **名称与唯一性**：项名是否允许 `sbin/init` 形式、长度上限、大小写敏感；`init_index` 必须唯一。

不要替用户选择；确认前不实现启动包解析。
